# 💻 Portfólio Pessoal — Kayky Fernando

Bem-vindo ao repositório do meu portfólio profissional! Este projeto foi desenvolvido para apresentar minha trajetória acadêmica, habilidades técnicas, certificações e projetos em desenvolvimento de software e web.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **HTML5 Semântico:** Estruturação acessível e otimizada para SEO.
- **CSS3 & Bootstrap 5.3:** Estilização responsiva, layout moderno e suporte a Dark Mode.
- **Bootstrap Icons:** Ícones vetoriais modernos integrados.
- **Glassmorphism / Backdrop Blur:** Design contemporâneo na barra de navegação.

---

## 📌 Seções do Portfólio

- **Hero / Início:** Apresentação pessoal e objetivo profissional.
- **Formação Acadêmica:** Detalhes dos cursos de Análise e Desenvolvimento de Sistemas (ADS) e Técnico em Desenvolvimento de Sistemas pelo SENAI-SP.
- **Habilidades & Conhecimentos:** Visão geral das competências em Front-end, Back-end (.NET / C#, Python), Bancos de Dados (SQL Server, MySQL), Segurança, Cloud e Inteligência Artificial.
- **Projetos em Destaque:** Links diretos para repositórios e *deploys* de projetos práticos.
- **Cursos e Certificações:** Tabela organizada com o status das qualificações concluídas e em andamento no SENAI.
- **Contato:** Links diretos para LinkedIn, GitHub e E-mail.
